| 2 | `AuditLogViewSet` | path param `id` untyped | consequence of #1 | docs show `id` as string instead of uuid | fixed by #1 |
| 3 | `NotificationViewSet` | could not obtain queryset (exception) | same as #1 | same | same |
| 4 | `NotificationViewSet` | path param `id` untyped | consequence of #3 | same | same |
| 5 | `MemberViewSet` | path param `id` untyped | plain `ViewSet` has no queryset to infer the uuid type | docs only | `@extend_schema_view` / `OpenApiParameter(uuid)` |
| 6 | `RoleViewSet` | path param `id` untyped | same as #5 | docs only | same |
| 7 | `PlatformOrganizationViewSet` | path param `id` untyped | same as #5 | docs only | same |
